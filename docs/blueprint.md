# **App Name**: Simple Guestbook

## Core Features:

- Message Input: Allow users to enter their message.
- Name Input: Allow users to enter their name.
- Website Input: Allow users to enter their website address.
- Guestbook Submission: Store all submitted data into TursoDB.
- Guestbook Display: Display submitted guestbook entries.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to give the design a simple friendly base color.
- Background color: Very light grey (#F0F0F0), providing a neutral backdrop.
- Accent color: Soft green (#90EE90) for submission button, to suggest positive action.
- Body and headline font: 'PT Sans', a humanist sans-serif suitable for headlines or body text
- Basic, unstyled HTML layout.
